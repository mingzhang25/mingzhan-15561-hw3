# Northwind Traders: AI-Assisted Business Data Analysis

Reproducible Python analysis behind the webpage **[Northwind Traders: Where to Grow, What to Fix](https://mingzhan-15561-hw3.netlify.app/)** (15.561, HW3).

The analysis answers four business questions from the Northwind Traders sample database (830 orders, 2,155 order lines, 4 July 1996 to 6 May 1998):

| # | Question | Script | Figures | Tables |
|---|----------|--------|---------|--------|
| 1 | Which customer markets are growing or shrinking, and where should sales attention go? | `src/q1_markets.py` | `q1_monthly_revenue.png`, `q1_country_change.png` | `q1_markets.csv` |
| 2 | Are discounts winning more business, or just giving away revenue? | `src/q2_discounts.py` | `q2_quantity_by_discount.png`, `q2_discount_dollars.png` | `q2_discount_tiers.csv`, `q2_customer_discount_rates.csv` |
| 3 | How dependent are we on a few big customers, and which valuable customers are drifting away? | `src/q3_customers.py` | `q3_pareto.png`, `q3_at_risk.png` | `q3_customers.csv`, `q3_at_risk_customers.csv` |
| 4 | Are we shipping on time, and what causes late shipments? | `src/q4_shipping.py` | `q4_days_vs_promise.png`, `q4_late_rates.png` | `q4_late_by_*.csv` |

## Repository layout

```
data/northwind.xlsx      Northwind database (Excel workbook supplied for the course)
src/data.py              Loading, cleaning, revenue calculation, integrity checks
src/style.py             Shared chart style and colour palette
src/q1_*.py ... q4_*.py  One script per business question
src/run_all.py           Runs everything; entry point
docs/index.html          The webpage (deployed on Netlify from /docs)
docs/figures/            Charts generated by the scripts (used by the webpage)
outputs/tables/          CSV tables behind every chart and number
outputs/results.json     Every headline number quoted on the webpage
```

## How to reproduce

Requires Python 3.10+ (developed on Python 3.13).

```bash
git clone https://github.com/mingzhang25/mingzhan-15561-hw3.git
cd mingzhan-15561-hw3
cd "HW3_AI-Assisted Business Data Analysis"
python -m venv .venv
# Windows: .venv\Scripts\activate    macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
python src/run_all.py
```

This regenerates every file in `docs/figures/` and `outputs/`, and prints the key numbers (also saved to `outputs/results.json`). Open `docs/index.html` in a browser to view the page locally.

To check a number on the webpage, find it in `outputs/results.json` or in the matching CSV in `outputs/tables/`.

## Data preparation and analytical choices

- **Revenue** = `UnitPrice × Quantity × (1 − Discount)` from the *Orders Details* sheet. This is the price actually charged on each order, which differs from the current list price in the *Product* sheet for about 30% of lines.
- **Partial periods.** Data starts 4 July 1996 and ends 6 May 1998. Growth comparisons use the same complete months in both years (January–April 1997 vs 1998). The monthly trend stops at April 1998.
- **Market** = the customer's country in the *Customers* sheet (it differs from the ship-to country for 4 orders).
- **Discount tiers.** Northwind uses 5/10/15/20/25%. Eight lines with unusual 1–6% discounts are grouped with the 5% tier ("1–6%").
- **At-risk customers (Q3).** At least 3 orders, and silent for 60+ days, and silent for more than 2× the customer's own median gap between orders, as of 6 May 1998. The thresholds are constants at the top of `q3_customers.py`.
- **Late shipment (Q4)** = shipped after the order's `RequiredDate`. The 21 unshipped orders were all placed after 8 April 1998 and none was overdue on 6 May 1998, so they are excluded. Rates are shown with 95% Wilson confidence intervals. Groups with fewer than 20 orders are left off the chart but kept in the CSVs.
- `src/data.py: check_data()` asserts basic integrity (unique order IDs, no orphan order lines, discounts between 0 and 1, every country mapped to a region) before any analysis runs.
